## 1. Configuration Files Overview

| File | Purpose | Created by |
|---|---|---|
| `~/.config/opencode/opencode.jsonc` | Main OpenCode config (providers, models, plugins, MCPs, instructions) | `configure_opencode()` |
| `~/.config/opencode/system_info.md` | AI instructions + system hardware info | `configure_opencode()` |
| `~/.bashrc` / `~/.zshrc` / `~/.profile` | Shell environment exports (`TERMINAL`, `OPENCODE_AGENTS_SWITCH_SINGLE_MODEL`) | `configure_default_terminal()` |
| `~/.config/wezterm/wezterm.lua` | WezTerm appearance, hotkeys, splits | `configure_wezterm()` |
| `config/variables.conf` | Preset definitions (plugins, MCPs per preset) | Manual editing |
| `config/plugins.conf` | Available plugins list | Manual editing |
| `config/mcp.conf` | Available MCP servers list | Manual editing |

## 2. Agent Configuration in OpenCodeWizard.sh (Before Install)

### 2.1 Presets

Presets are defined in `config/variables.conf`:

```bash
PRESET_DEVELOPER="developer"
PRESET_STANDARD="standard"
PRESET_MINIMAL="minimal"
```

Each preset defines which plugins and MCP servers are installed:

```bash
PRESET_DEVELOPER_PLUGINS=(
    "oh-my-openagent"
    "opencode-mem"
    "@different-ai/opencode-browser"
    "@tarquinen/opencode-smart-title"
    "opencode-token-speed-plugin"
    "opencode-codebase-index"
)
PRESET_DEVELOPER_MCPS=(
    "fetch" "puppeteer" "postgres" "context7"
    "codegraph" "docs-mcp" "lsp-mcp"
)
```

**To modify:** Edit `config/variables.conf` — add or remove entries from the arrays.

### 2.2 Plugins List

Defined in `config/plugins.conf`:

```text
oh-my-openagent|Session management and advanced CLI commands
opencode-mem|Long-term Rust RAG memory with hybrid search
@different-ai/opencode-browser|Integration with a real web browser
```

**To modify:** Edit `config/plugins.conf`. Comment lines with `#` to disable, add new lines to enable.

### 2.3 MCP Servers List

Defined in `config/mcp.conf`:

```text
fetch|Web fetch MCP|npx -y mcp-server-fetch-typescript
puppeteer|Browser automation|npx -y @modelcontextprotocol/server-puppeteer
docs-mcp|Document reader (PDF, DOCX, etc)|docling
```

**To modify:** Edit `config/mcp.conf`. Comment lines with `#` to disable, add new lines to enable.

### 2.4 How the Script Generates Configs

The function `configure_opencode()` in `OpenCodeWizard.sh`:

1. Reads preset lists (`preset_plugins`, `preset_mcps`) from `variables.conf`
2. Builds JSON for `opencode.jsonc` with selected plugins and MCPs
3. Writes `system_info.md` with system hardware and critical rules
4. Sets `opencode.jsonc` to reference `system_info.md` via `"instructions"`

### 2.5 System Info File (system_info.md)

Generated by `configure_opencode()` in `OpenCodeWizard.sh` (line ~1668):

```markdown
# GIT OPERATIONS RULE (CRITICAL - FIRST PRIORITY)

**ABSOLUTE PROHIBITION: Never commit or push to git without explicit user confirmation.**
...
# System Environment Details
- **Operating System:** ...
- **User Shell:** ...
```

The critical rules appear **first**, before hardware details, to ensure maximum visibility.

## 3. Agent Configuration After Installation (Manual)

### 3.1 Main OpenCode Config

Edit `~/.config/opencode/opencode.jsonc`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "instructions": [
    "~/.config/opencode/system_info.md"
  ],
  "provider": {
    "my-provider": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "My Provider",
      "options": {
        "baseURL": "http://localhost:8080/v1"
      },
      "models": {
        "my-model": {
          "name": "My Model",
          "limit": { "context": 128000, "output": 65536 }
        }
      }
    }
  },
  "plugin": [
    "oh-my-openagent",
    "opencode-mem"
  ],
  "mcp": {
    "fetch": {
      "type": "local",
      "command": ["npx", "-y", "mcp-server-fetch-typescript"],
      "enabled": true
    }
  }
}
```

**To add/remove plugins:** Edit the `"plugin"` array.

**To add/remove MCP servers:** Edit the `"mcp"` object.

**To add custom instructions:** Add file paths to the `"instructions"` array. Files are read in order — first file = highest priority.

### 3.2 Adding Custom Instruction Files

Create a new `.md` file with rules, then add it to `opencode.jsonc`:

```bash
echo "# My custom rules" > ~/.config/opencode/custom_rules.md
```

Then in `opencode.jsonc`:

```json
"instructions": [
  "~/.config/opencode/custom_rules.md",
  "~/.config/opencode/system_info.md"
]
```

Files are processed in order. The first file has the highest priority.

### 3.3 Provider & Model Configuration

Add or modify providers in the `"provider"` section of `opencode.jsonc`:

```json
"provider": {
  "my-local": {
    "npm": "@ai-sdk/openai-compatible",
    "name": "Local LLM",
    "options": {
      "baseURL": "http://localhost:8080/v1"
    },
    "models": {
      "my-model-v1": {
        "name": "Model v1",
        "limit": { "context": 32000, "output": 4096 }
      }
    }
  }
}
```

### 3.4 Shell Configuration

The script exports environment variables in `~/.bashrc`, `~/.zshrc`, and `~/.profile`:

```bash
# OpenCode
export TERMINAL=wezterm
export OPENCODE_AGENTS_SWITCH_SINGLE_MODEL=true
```

**To modify manually:** Edit any of these files and restart your shell or `source` the file.

## 4. Critical Git Operations Rule

### Where it's defined

1. **Global:** `~/.config/opencode/system_info.md` (added manually)
2. **Generated:** The script creates it automatically in the same file via `configure_opencode()`

### The rule

```text
ABSOLUTE PROHIBITION: Never commit or push to git without explicit user confirmation.

- Before git commit: ask "Commit changes?"
- Before git push: ask "Push to remote?"
- Wait for explicit "yes"/"да"/"push"/"коммить" before proceeding.
- NO auto-commit, NO auto-push, NO --no-verify shortcuts.
```

### Why it's first

The `"instructions"` array in `opencode.jsonc` processes files in order. `system_info.md` is the first (and currently only) file listed. Within it, the git rule is placed **before** system hardware details — making it the very first instruction the AI reads.

## 5. Tab Switching Behavior

### What it does

By default, pressing **Tab** in OpenCode may change both the **agent mode** (Agent/Edit/Search) and the **AI model**. This can be inconvenient — switching mode shouldn't reset your model.

### The fix

```bash
export OPENCODE_AGENTS_SWITCH_SINGLE_MODEL=true
```

When set, **Tab switches only the mode**, keeping the current model active.

### Where it's set

1. **By the script:** `configure_default_terminal()` appends it to `~/.bashrc`, `~/.zshrc`, and `~/.profile`
2. **Manually:** Add the export to your shell config and reload:

```bash
echo 'export OPENCODE_AGENTS_SWITCH_SINGLE_MODEL=true' >> ~/.bashrc
source ~/.bashrc
```

1. **Temporarily:** Export it for the current session:

```bash
export OPENCODE_AGENTS_SWITCH_SINGLE_MODEL=true
```

### Verification

```bash
echo $OPENCODE_AGENTS_SWITCH_SINGLE_MODEL
# Should output: true
```
