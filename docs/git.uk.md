# Посібник зі встановлення Git

*Читати іншими мовами: [English (git.md)](git.md)*

[Git](git.uk.md) — це безкоштовна розподілена система керування версіями з відкритим вихідним кодом, розроблена для швидкого та ефективного керування будь-якими проектами, від малих до дуже великих. Цей посібник допоможе вам встановити [Git](git.uk.md) на вашу операційну систему.

---

## 1. Windows

### Варіант А: Через пакетний менеджер Windows (`winget`) (Рекомендовано)
1. Відкрийте PowerShell або командний рядок.
2. Виконайте наступну команду:
   ```powershell
   winget install --id Git.Git -e --source winget
   ```
3. Перезапустіть сесію терміналу, щоб зміни набрали чинності.

### Варіант Б: Через автономний інсталятор
1. Завантажте інсталятор з офіційного сайту: [git-scm.com](https://git-scm.com/download/win).
2. Запустіть завантажений файл `.exe`.
3. Дотримуйтесь інструкцій майстра встановлення (для більшості користувачів рекомендуються налаштування за замовчуванням).

---

## 2. macOS

### Варіант А: Через Homebrew (Рекомендовано)
1. Відкрийте термінал.
2. Встановіть [Git](git.uk.md), виконавши команду:
   ```bash
   brew install git
   ```

### Варіант Б: Через інструменти командного рядка Xcode
1. Відкрийте термінал.
2. Введіть наступну команду та натисніть Enter:
   ```bash
   git --version
   ```
3. Якщо [Git](git.uk.md) ще не встановлено, з'явиться вікно із запитом на встановлення. Натисніть кнопку **Встановити** (Install) та дотримуйтесь інструкцій.

---

## 3. Linux

Встановіть [Git](git.uk.md) за допомогою пакетного менеджера вашого дистрибутива:

### Debian / Ubuntu
```bash
sudo apt update
sudo apt install git -y
```

### Fedora / RHEL
```bash
sudo dnf install git -y
```

### Arch Linux / CachyOS
```bash
sudo pacman -S git --noconfirm
```

---

## Перевірка встановлення

Після встановлення переконайтеся, що [Git](git.uk.md) встановлено успішно, запустивши наступну команду в новому вікні терміналу:
```bash
git --version
```
Ви маєте побачити встановлену версію [Git](git.uk.md), наприклад: `git version 2.45.0`.
