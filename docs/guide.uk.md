## 1. Клонування репозиторію

Щоб скопіювати цей проект на свій комп'ютер, відкрийте ваш поточний системний терміналі та виконайте:

> [!NOTE]
> Переконайтеся, що у вас встановлено [Git](git.uk.md). Детальніше див. у [Посібнику зі встановлення Git](git.uk.md).

```bash
git clone https://github.com/nudykw/OpenCodeWizard.git
cd OpenCodeWizard
```

## 2. Запуск майстра налаштування

### Linux та macOS:
1. Зробіть скрипт виконуваним:
   ```bash
   chmod +x OpenCodeWizard.sh
   ```
2. Запустіть скрипт:
   ```bash
   ./OpenCodeWizard.sh
   ```

### Windows 11:
1. Відкрийте PowerShell **від імені Адміністратора**.
2. Запустіть скрипт:
   ```powershell
   Set-ExecutionPolicy Bypass -Scope Process -Force
   .\OpenCodeWizard.ps1
   ```

> **Порада щодо налаштування:** Усі рекомендовані опції вибрані за замовчуванням. Для швидкої установки просто оберіть мову (2 - українська) та натискайте **Enter** на всіх наступних кроках.

## 3. Запуск WezTerm та OpenCode

Після завершення роботи скрипта запустіть додаток **WezTerm** (через ярлик на Робочому столі або у списку програм вашої системи).

- Щоб відкрити ШІ-асистента у терміналі, натисніть комбінацію клавіш:
  `CTRL + SHIFT + O`
- Це автоматично розділить екран терміналу по вертикалі та запустить **OpenCode** у правій панелі.

---

### Відкриття WezTerm у потрібній папці

OpenCode працює з **поточною директорією** — він може бачити всі файли в папці, де було відкрито термінал. Щоб працювати з вашими документами, завжди відкривайте WezTerm у папці, де знаходяться ваші файли.

#### Linux

| Файловий менеджер | Як відкрити термінал тут |
| --- | --- |
| **Nautilus** (GNOME, Ubuntu) | Клацніть правою кнопкою в папці → **Відкрити в терміналі** (або натисніть `Ctrl+T`, якщо плагін терміналу активовано) |
| **Dolphin** (KDE) | Клацніть правою кнопкою в папці → **Відкрити термінал** (або натисніть `F4`) |
| **Thunar** (XFCE) | Клацніть правою кнопкою → **Відкрити термінал тут** |
| **Nemo** (Cinnamon) | Клацніть правою кнопкою → **Відкрити в терміналі** |
| Будь-який менеджер | Перейдіть у папку, потім натисніть `` Ctrl+` `` (апостроф), щоб відкрити вбудовану панель терміналу (якщо доступно) |

> **Порада:** Якщо "Відкрити в терміналі" не з'являється, можливо, потрібно встановити плагін терміналу для вашого файлового менеджера:
> ```bash
> # Для Nautilus (Ubuntu/Debian)
> sudo apt install nautilus-extension-gnome-terminal
>
> # Для Nautilus з WezTerm
> sudo apt install nautilus-open-any-terminal
> ```

#### Windows 11

1. Відкрийте **Провідник (File Explorer)** і перейдіть у потрібну папку
2. **Shift + клацніть правою кнопкою** на порожньому місці всередині папки
3. Оберіть **Відкрити в терміналі (Open in Terminal)** (відкриває Windows Terminal)
4. Введіть `wezterm` та натисніть Enter, **або** встановіть WezTerm терміналом за замовчуванням (див. [Встановлення WezTerm терміналом за замовчуванням](../README.uk.md#встановлення-wezterm-терміналом-за-замовчуванням))

> **Альтернатива:** Введіть `cmd` або `powershell` в адресному рядку Провідника та натисніть Enter — термінал відкриється в цій папці. Потім виконайте `wezterm` для переходу.

#### macOS

1. Відкрийте **Finder** і перейдіть у потрібну папку
2. **Клацніть правою кнопкою** на папці (або Ctrl+Click)
3. Перейдіть до **Services** → **New Terminal at Folder**
4. Відкриється термінал за замовчуванням (Terminal.app або iTerm2). Щоб використовувати WezTerm, встановіть [WezTerm CLI](https://wezfurlong.org/wezterm/install.html) та виконайте:
   ```bash
   # З будь-якого терміналу, відкрити WezTerm у поточній папці
   wezterm start
   ```

> **Порада:** Щоб додати WezTerm на панель інструментів Finder, перетягніть `/Applications/WezTerm.app` на панель, утримуючи `Cmd`.

> **💡 Контекстне меню Windows:** Якщо ви встановили контекстне меню під час налаштування — права кнопка на папці → **"Open in OpenCode"** запускає WezTerm+OpenCode в цій папці. На **Windows 11** натисніть **`Shift + F10`** або **"Показати більше параметрів"**. Повний довідник: [Особливості для Windows](../README.uk.md#-особливості-для-windows).

### Базові дії з текстом у WezTerm на Windows

WezTerm — це термінал, а не звичайний текстовий редактор. Миша та буфер обміну працюють тут інакше:

| Дія | Як зробити |
|---|---|
| **Виділити / скопіювати текст** | Затисніть **ліву кнопку миші** та протягніть по тексту — після відпускання текст **автоматично копіюється** у буфер обміну. Жодних додаткових клавіш не потрібно. |
| **Виділити слово** | **Подвійний клік** по слову — виділяє і копіює. |
| **Виділити рядок** | **Потрійний клік** по рядку — виділяє і копіює. |
| **Вставити текст** | **Права кнопка миші** в будь-якому місці термінала, **або** натисніть **`CTRL + SHIFT + V`**. |
| **Вставити зображення** | **`CTRL + SHIFT + I`** (див. [Робота зі скріншотами](#робота-зі-скріншотами) вище). |

> **Чому не `CTRL+C` / `CTRL+V`?** У терміналах `CTRL+C` — це сигнал "перервати" (зупиняє виконання команди), а `CTRL+V` часто перехоплюється програмами всередині термінала. WezTerm використовує `CTRL+SHIFT+C/V` для копіювання/вставки, щоб уникнути конфліктів. Але якщо ви просто виділили текст мишею — він уже в буфері обміну, клавіші не потрібні.

## 4. Вибір моделі штучного інтелекту

За замовчуванням комбінація `CTRL + SHIFT + O` запускає OpenCode з безкоштовною та швидкою моделлю:
```bash
opencode -m opencode/deepseek-v4-flash-free
```

Якщо ви хочете використовувати інші моделі (наприклад, Claude 3.5 Sonnet чи GPT-4o), ви можете перемикати їх прямо у вікні чату:
1. Напишіть `/models`, щоб побачити список доступних моделей.
2. Напишіть `/model провайдер/назва-моделі` (наприклад, `/model openrouter/anthropic/claude-3.5-sonnet`), щоб перемкнутися на неї.

> **Примітка:** Для роботи з платними моделями необхідно поповнити баланс особистого кабінету OpenCode.

---

> **💡 Чому контекст важливий**
>
> Двоє дивляться у вікно:
>
> — *Бачиш того чоловіка через дорогу? Вгадай його ім'я.*
> — *Гадки не маю. Може бути будь-яке.*
> — *Ось саме. Без **контексту** — хто він, звідки, що я про нього знаю — можна лише вгадувати.*
>
> Те саме зі ШІ. Воно багато знає, але без деталей про *вашу* ситуацію може лише вгадувати. У нього є два джерела: те, що ви написали в запиті, і те, що воно може дізнатися самостійно за допомогою інструментів **MCP**.
>
> Запитайте *"котра година?"* — ШІ перевірить сервер часу, знайде вашу IP-адресу, визначить часовий пояс. Працює, але займає місце. Запитайте *"котра година в Нью-Йорку?"* — один інструмент. Швидше.
>
> **Немає контексту = вгадування. Контекст = знання. MCP = бачити на власні очі.**
>
> ---

> **💡 Спробуйте відчути контекст самі**
> 
> Ви думаєте, що ШІ «тупить» або вигадує нісенітницю? Давайте перевіримо вас у тих самих умовах, у яких працює модель без належного контексту.
> 
> **Завдання:** Швидко дайте відповідь на запитання: 
> *«Скільки буде 5 + ... = ?»*
> 
> **Ваша реакція:** Ви, мабуть, відчули роздратування або розгубленість. Чому? 
> 1. Ви не знаєте, яке число стоїть на місці пропуску.
> 2. Ви не знаєте, який має бути результат (це має бути 10? чи 5 + 50?).
> 3. Вам не вистачає «контексту» завдання.
> 
> **Висновок:** Ви не «гальмуєте», ви просто не можете дати точну відповідь, бо вам дали лише фрагмент умови. Те саме відбувається з ШІ: якщо ви просите його «полагодити код» або «підсумувати документ», не надавши доступу до файлів або не пояснивши суть завдання — він починає «вгадувати». 
> 
> **Дайте ШІ контекст — і він перестане гадати.**

## 5. Як користуватися OpenCode

OpenCode може взаємодіяти з вашою системою за допомогою текстових інструкцій звичайною мовою (українською або англійською):

> **💡 Робота з сесіями:** Кожна розмова в OpenCode — це окрема **сесія**. Для найкращих результатів використовуйте нові сесії для різних завдань — [дізнайтеся більше про сесії](sessions.uk.md).

### Робоча директорія та доступ до файлів

OpenCode автоматично має доступ до **всіх файлів у папці, де ви його запустили** (поточна робоча директорія). Це означає:

- Ви можете попросити AI читати, шукати або змінювати будь-які файли в цій папці
- AI може переходити в **підпапки** і працювати з файлами там
- До файлів **поза** поточною директорією також можна отримати доступ, якщо вказати повний шлях, але зручніше відкривати OpenCode у папці, з якою ви хочете працювати

> **Коротко:** Папка, в якій ви відкрили термінал = папка, яку бачить OpenCode. Якщо ваші документи в `~/Документи/Звіти/`, відкривайте термінал там.

### Взаємодія з файлами
- Ви можете давати запити кшталт:
  - *"Прочитай файл `src/App.js` і поясни, що він робить."*
  - *"Допоможи мені додати новий роут у файл `routes/users.js`."*
  - *"Знайди в цій папці всі файли, які містять слово 'database'."*
  - *"Підсумуй всі PDF файли в папці `reports/`."*
  - *"Знайди у всіх документах щось пов'язане з бюджетом 2024."*
  - *"Створи нову папку `нотатки` і збережи туди підсумок."*
  - *"Порівняй CSV файли в цій папці і скажи, що змінилося."*

### Використання плагінів
- **`opencode-mem`** допомагає ШІ запам'ятовувати важливу інформацію між різними чат-сесіями.
- **`opencode-token-speed-plugin`** у реальному часі показує швидкість виведення відповіді (кількість токенів на секунду, TPS).

### Робота з MCP-серверами

[Прочитайте детальний посібник про доступні MCP-сервери](mcp/mcp.uk.md), щоб зрозуміти, які інструменти доступні та чому варто використовувати їх вибірково для підтримки якості контексту.

### Робота зі скріншотами
OpenCode підтримує інтеграцію з браузером через MCP-сервер `puppeteer` або плагін `@different-ai/opencode-browser`.
1. **Зняття скріншоту**: Просто попросіть: *"Зроби скріншот https://github.com"* або *"Візуалізуй інтерфейс http://localhost:3000 та покажи мені"*.
2. **Візуальна перевірка**: ШІ-агент запустить безголовий браузер, перейде за вказаною адресою, зробить знімок екрана та проаналізує його вміст, щоб допомогти вам.
3. **Відображення в терміналі**: Завдяки WezTerm, усі зроблені скріншоти будуть відображатися безпосередньо всередині вікна терміналу (inline). Ви зможете бачити саме те, що бачить ШІ, без необхідності відкривати сторонні програми для перегляду зображень.
4. **Вставка скріншотів з буфера обміну (⚠️ Не звичайна вставка)**:
   - **⚠️ Це НЕ звичайний `CTRL+V`.** `CTRL+SHIFT+I` — це **незвичайний буфер обміну**, вбудований у конфіг WezTerm: він зберігає зображення з буфера у файл на диску (`~/Pictures/opencode_screenshots/`) і друкує `@/шлях/до/zображення.png`, щоб OpenCode міг прочитати його через `docs-mcp`.
   - Зробіть скріншот за допомогою системного шорткату (наприклад, `PrintScreen`, `Win+Shift+S` або `Cmd+Shift+4` на macOS), щоб він зберігся у вашому буфері обміну.
   - Клацніть усередині активної панелі чату OpenCode у WezTerm і натисніть комбінацію клавіш **`CTRL + SHIFT + I`**.
   - Вбудований скрипт майстра налаштування автоматично збереже зображення з буфера у вашу папку зображень (`~/Pictures/opencode_screenshots/`) і вставить посилання `@/шлях/до/файлу.png` безпосередньо в рядок введення запиту.
5. **Перетягування файлів (Drag and Drop)**: Ви також можете перетягнути будь-який файл зображення безпосередньо у вікно терміналу або вручну написати символ `@` та шлях до файлу (наприклад, `@/шлях/до/зображення.png`), щоб прикріпити його до повідомлення.

## 6. Налаштування плагінів та MCP-серверів

Ви можете легко змінити, які плагіни та MCP-сервери будуть встановлені майстром, без жодних навичок програмування.

Відкрийте файл `OpenCodeWizard.sh` (або `OpenCodeWizard.ps1` на Windows) у текстовому редакторі та знайдіть масиви на самому початку скрипта:

```bash
OPENCODE_PLUGINS=(
    "oh-my-openagent|Керування сесіями та додаткові команди"
    "opencode-mem|Векторна та довгострокова пам'ять"
)

OPENCODE_MCP_SERVERS=(
    "fetch|Швидке читання сайтів|npx -y mcp-server-fetch-typescript"
)
```

- **Щоб додати плагін:** Додайте новий рядок у форматі `"назва-плагіна|Опис"`.
- **Щоб вимкнути MCP-сервер:** Додайте символ `#` на початку рядка, щоб закоментувати його.
- Запустіть скрипт ще раз (`./OpenCodeWizard.sh --silent`), щоб застосувати зміни.

## 7. Резервні копії та відновлення

Майстер налаштування дбає про безпеку ваших даних. Кожного разу, коли він змінює конфігураційний файл, створюється транзакційна резервна копія.

Якщо ви захочете повернутися до попередніх налаштувань, скористайтеся вбудованими CLI командами:

- `./OpenCodeWizard.sh --create-backup` : Створити резервну копію вручну.
- `./OpenCodeWizard.sh --restore-backup` : Відкрити інтерактивне меню для перегляду та відновлення попередньої резервної копії.
- `./OpenCodeWizard.sh --remove-backups` : Видалити всі збережені резервні копії.
- `./OpenCodeWizard.sh --reset` : Видалити всі налаштування майстра та почати з чистого аркуша.

*(На Windows використовуйте `.\OpenCodeWizard.ps1 -RestoreBackup` тощо)*
