# Довідник гарячих клавіш WezTerm

## Стандартні спліти

| Хоткей | Дія |
| ------ | --- |
| `CTRL+SHIFT+D` | Розділити панель по горизонталі (вниз, 50%) |
| `CTRL+SHIFT+E` | Розділити панель по вертикалі (вправо, 50%) |
| `CTRL+SHIFT+W` | Закрити поточну панель (з підтвердженням) |

## Пресет для розробників (з підтримкою git)

| Хоткей | Дія |
| ------ | --- |
| `CTRL+SHIFT+O` | Розділити поточну панель: gitui (вгорі зліва, 28%) + спільний термінал (внизу зліва, 12%) + OpenCode (справа, 60%) |
| `CTRL+SHIFT+G` | Такий самий макет у **новій вкладці** |
| `CTRL+SHIFT+ALT+G` | Такий самий макет у **новій робочій області** |

### Деталі гарячих клавіш

Усі три комбінації клавіш створюють однаковий макет із 3 панелей, але відрізняються тим, **де** вони його створюють. Макет завжди складається з: gitui (вгорі зліва, 40% ширини × 70% висоти), спільного терміналу (внизу зліва, 40% × 30%) та OpenCode (справа, 60% ширини).

#### `CTRL+SHIFT+O` — Спліт у поточній панелі

- **Де**: Розділяє **поточну панель** на макет із 3 панелей.
- **Коли використовувати**: Ви перебуваєте в командному рядку (shell) і хочете почати програмувати прямо тут.
- **Обмеження**: Якщо ви натиснете це **всередині OpenCode** (не з shell), шлях до скрипта буде надіслано як текст у чат OpenCode замість виконання. У такому разі використовуйте `CTRL+SHIFT+G`.
- **Макет**:
  ```
  ┌───────────────────┬───────────────────┐
  │ gitui / shell      │                   │
  │ (вгорі зліва, 70%) │  OpenCode (60%)   │
  ├───────────────────┤                   │
  │ спільний термінал  │                   │
  │ (внизу зліва, 30%) │                   │
  └───────────────────┴───────────────────┘
  ```

#### `CTRL+SHIFT+G` — Спліт у новій вкладці

- **Де**: Створює **нову вкладку WezTerm** із макетом із 3 панелей.
- **Коли використовувати**: Ви хочете залишити поточну вкладку недоторканою та працювати в окремій вкладці.
- **Перевага**: Працює **звідусіль** — навіть якщо ви перебуваєте всередині OpenCode, `vim` або будь-якої іншої програми. Нова вкладка завжди запускається зі свіжим shell, тому скрипт працює надійно.
- **Макет**: Такий самий, як у `CTRL+SHIFT+O`, але в новій вкладці.

#### `CTRL+SHIFT+ALT+G` — Спліт у новій робочій області

- **Де**: Створює **нову робочу область WezTerm** (з назвою `git`) із макетом із 3 панелей.
- **Коли використовувати**: Ви хочете **повної ізоляції** — перемикайтеся між робочими областями, як між віртуальними робочими столами. Кожна робоча область має власний набір вкладок і панелей.
- **Перевага**: Працює звідусіль (як і `G`). Робочі області зберігаються, доки ви їх не закриєте. Перемикайтеся між ними за допомогою перемикача робочих областей WezTerm.
- **Макет**: Такий самий, як у `CTRL+SHIFT+O`, але в новій робочій області.

#### Умовний запуск gitui

- Якщо поточний каталог (або його батьківський) **є git-репозиторієм** → gitui запускається автоматично у верхній лівій панелі.
- Якщо каталог **НЕ є git-репозиторієм** → у верхній лівій панелі просто відображається звичайний командний рядок (без gitui).

### Спільний термінал

**Спільний термінал** (внизу зліва) — це звичайний shell, у який AI-бот може надсилати команди. Це дозволяє просити AI виконувати команди, не виходячи з чату.

**Використання:**
1. Натисніть одну з гарячих клавіш вище (з shell, а не з OpenCode).
2. gitui відкриється вгорі зліва (тільки якщо папка є git-репозиторієм).
3. OpenCode запуститься в правій панелі.
4. Запитайте AI: *"Запусти \`npm install\` у спільному терміналі"*.
5. AI надішле команду через `wezterm cli send-text`.
6. Перевірте результат у нижній лівій панелі.

> **Примітка:** gitui з'являється лише тоді, коли поточна папка є git-репозиторієм. Без git макет містить лише спільний термінал (зліва) + OpenCode (справа).

Дивіться [system_info.md](../.config/opencode/system_info.md), щоб дізнатися, як AI знаходить ID панелі спільного терміналу.
