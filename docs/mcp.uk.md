# Сервери Model Context Protocol (MCP)

MCP-сервери розширюють можливості ШІ, надаючи доступ до локальних систем та інструментів. Вони дозволяють ШІ "бачити" та "робити" більше всередині вашої системи.

## Доступні MCP-сервери

| MCP-сервер | Призначення |
| :--- | :--- |
| **[`fetch`](#fetch)** | Швидке зчитування веб-сторінок. |
| **[`puppeteer`](#puppeteer)** | Повна автоматизація браузера: кнопки, форми, скріншоти. |
| **[`postgres`](#postgres)** | Безпечний доступ до локальних баз даних. |
| **[`context7`](#context7)** | Актуальна документація бібліотек. |
| **[`codegraph`](#codegraph)** | Аналіз графа коду (AST). |
| **[`docs-mcp`](#docs-mcp)** | Читання документів (PDF, DOCX тощо). |
| **[`lsp-mcp`](#lsp-mcp)** | Інтелект коду (визначення, діагностика). |

---

## Деталі інструментів

### <a name="fetch"></a>`fetch`

Завантажує та аналізує текстовий вміст веб-сторінок.

* **Чому використовувати:** Замість того, щоб копіювати документацію вручну, просто дайте посилання ШІ. Він сам «відвідає» сторінку та прочитає текст.

### <a name="puppeteer"></a>`puppeteer`

Автоматизація браузера.

* **Чому використовувати:** Коли сторінка вимагає натискання кнопок або виконання JavaScript, щоб побачити контент. Це потужніше за [`fetch`](#fetch), але споживає більше ресурсів.

### <a name="postgres"></a>`postgres`

Підключення до локальних баз даних.

* **Чому використовувати:** Дозволяє ШІ напряму робити запити до вашої локальної бази даних, щоб знайти інформацію чи виправити помилки в даних.
* **Примітка:** Зазвичай цей інструмент не потрібен пересічному користувачу. Якщо ви не працюєте з базами даних, ви можете сміливо вимкнути його для економії ресурсів.

### <a name="context7"></a>`context7`

Документація бібліотек та приклади коду.

* **Чому використовувати:** Надає ШІ миттєвий доступ до найактуальнішої документації, описів функцій та прикладів використання програмних бібліотек.
* **Примітка:** Цей інструмент створений спеціально для програмістів. Він допомагає ШІ писати правильний код, «читаючи» актуальні посібники до бібліотек. Якщо ви не плануєте створювати власні програми чи скрипти, він вам не знадобиться, тому його можна вимкнути, щоб не займати місце в пам'яті ШІ.

### <a name="codegraph"></a>`codegraph`

Аналіз графа коду (AST).

* **Чому використовувати:** Дозволяє ШІ «намалювати карту» структури вашого коду. Він будує зв'язки між різними файлами, функціями та класами, допомагаючи ШІ розуміти архітектуру проєкту.
* **Примітка:** Цей інструмент призначений виключно для розробки програмного забезпечення. Він створює глибоке розуміння кодової бази, яке потрібно лише тоді, коли ви активно змінюєте або переписуєте код. Якщо ви просто працюєте з текстами чи документами, цей інструмент можна сміливо вимкнути.

### <a name="docs-mcp"></a>`docs-mcp`

Читання документів (PDF, DOCX, MD, CSV, зображення).

* **Чому використовувати:** Дозволяє ШІ читати та «спілкуватися» з файлами, які не є звичайним текстом.
* **Приклади того, що ви можете робити:**
  * **PDF:** «Зроби підсумок цього 50-сторінкового фінансового звіту у PDF».
  * **Зображення (OCR):** «Подивись на це фото рукописної нотатки та перепиши її в текст».
  * **Таблиці:** «Витягни підсумкову суму з цього бюджетного файлу CSV».
  * **Word:** «Перепиши цей чернетковий договір (DOCX) у більш професійному стилі».
* **Примітка:** Це один з найкорисніших інструментів для непрограмістів. Тримайте його увімкненим, якщо працюєте з офісними документами, сканами чи дослідницькими статтями. Він дуже легкий і активується лише тоді, коли ви прямо просите його прочитати якийсь документ.

### <a name="lsp-mcp"></a>`lsp-mcp`

Інтелект коду.

* **Чому використовувати:** Надає точну навігацію по коду (визначення, переходи, діагностика). Доповнює [`codegraph`](#codegraph), забезпечуючи точність на рівні IDE.
* **Для програмістів:** Необхідний інструмент. Він дозволяє ШІ:
  * **«Перейти до визначення»:** Миттєво знаходити, де визначена функція чи клас, навіть у величезних проєктах.
  * **Знаходити використання:** Бачити, де саме змінна чи метод використовуються в усій кодовій базі.
  * **Бачити помилки в реальному часі:** Виявляти помилки типів або синтаксису ще до того, як ви запустите код.
* **Для непрограмістів:** Скоріш за все, не потрібен. Це суто технічний інструмент для навігації в коді. Якщо ви не пишете програми, вимкнення цього інструмента дозволить заощадити пам'ять і тримати ШІ зосередженим на ваших завданнях.
