# Сервери Model Context Protocol (MCP)

MCP-сервери розширюють можливості ШІ, надаючи доступ до локальних систем та інструментів. Вони дозволяють ШІ "бачити" та "робити" більше всередині вашої системи.

## Доступні MCP-сервери

| MCP-сервер | Призначення |
| :--- | :--- |
| **`fetch`** | Швидко зчитує текстовий вміст веб-сторінок за посиланнями без запуску візуального вікна. |
| **`puppeteer`** | Повноцінна автоматизація браузера: ШІ може тиснути кнопки, робити скріншоти та заповнювати форми. |
| **`postgres`** | Прямий безпечний доступ до локальної бази даних (передустановлений для БД `gpt_chat_bot`). |
| **`context7`** | Актуальна документація бібліотек та приклади коду. |
| **`codegraph`** | AST-граф коду: семантичний пошук, аналіз викликів, impact analysis. |
| **`docs-mcp`** | Читання документів: PDF, DOCX, MD, CSV, OCR (через `go-docs-mcp`). |
| **`lsp-mcp`** | Інтелект коду: визначення, референси, діагностика через LSP. |

## Чому варто використовувати MCP?

* **Економія контекстного вікна:** Замість того, щоб вставляти величезні документації або вручну парсити файли, ШІ сам завантажує лише те, що йому потрібно.
* **Видимість системи:** MCP дає ШІ інструменти для вивчення вашої системи — бази даних, браузер та граф коду — замість того, щоб покладатися на "вгадування" зі своїх тренувальних даних.
* **Розширюваність:** Екосистема MCP відкрита. Ви можете додати підтримку нових форматів, API або спеціальних інструментів, додаючи нові MCP-сервери.
