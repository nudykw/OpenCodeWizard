# Документація плагінів OpenCode

*Читати іншими мовами: [English (plugins.md)](plugins.md)*

Цей посібник містить детальний опис доступних плагінів для OpenCode, їх призначення та сценарії використання.

## Огляд плагінів

| Назва плагіна | Опис | Найкраще для |
| :--- | :--- | :--- |
| **`oh-my-openagent`** | Основний плагін для керування сесіями та розширених команд CLI. | Усіх користувачів (обов'язково) |
| **`opencode-mem`** | Довгострокова пам'ять RAG (Rust) з гібридним пошуком. | Аналітиків, дослідників, розробників |
| **`@different-ai/opencode-browser`** | Інтеграція з реальним браузером для веб-досліджень. | Дослідників, копірайтерів |
| **`@tarquinen/opencode-smart-title`** | Автоматично створює заголовки для сесій чату. | Організованих користувачів |
| **`opencode-token-speed-plugin`** | Відстеження продуктивності в реальному часі (токенів/сек). | Досвідчених користувачів |
| **`opencode-codebase-index`** | Семантичне індексування бази коду з авто-оновленням. | Розробників |

---

## Детальний опис плагінів

### 1. `oh-my-openagent`

* **Що робить:** Забезпечує фундаментальну оркестрацію сесій, утиліти робочого простору та розширені допоміжні команди CLI, необхідні для ефективної роботи OpenCode.
* **Кому потрібно:** Усім. Це «серце» OpenCode.
* **Навіщо встановлювати:** Необхідно для керування сесіями чату та доступу до розширених функцій асистента.

### 2. `opencode-mem`

* **Що робить:** Реалізує довгострокову пам'ять RAG (Retrieval-Augmented Generation) на Rust. Використовує гібридний пошук (BM25 + вектори) для згадування минулих взаємодій.
* **Кому потрібно:** Дослідникам, письменникам та розробникам, що працюють над довгостроковими проєктами.
* **Навіщо встановлювати:** Дозволяє ШІ зберігати контекст між різними днями та сесіями.

### 3. `@different-ai/opencode-browser`

* **Що робить:** Надає ШІ доступ до повноцінного браузера (headless). Він може навігувати, збирати контент та взаємодіяти з динамічними сайтами.
* **Кому потрібно:** Письменникам, дослідникам та всім, кому потрібні свіжі дані з мережі.
* **Навіщо встановлювати:** Дозволяє ШІ перевіряти інформацію та виконувати завдання, що виходять за межі його статичних знань.

### 4. `@tarquinen/opencode-smart-title`

* **Що робить:** Аналізує вміст вашого чату та автоматично перейменовує сесію на більш змістовну.
* **Кому потрібно:** Користувачам, які тримають багато відкритих чатів.
* **Навіщо встановлювати:** Замінює стандартні заголовки типу "New Chat" на контекстно-залежні назви.

### 5. `opencode-token-speed-plugin`

* **Що робить:** Надає моніторинг продуктивності в реальному часі, включаючи TPS (токенів за секунду), середню швидкість (AVG) та TTFT (час до отримання першого токена).
* **Кому потрібно:** Користувачам, орієнтованим на продуктивність, та тим, хто займається діагностикою затримок.
* **Важливо:** Не встановлюйте кілька плагінів швидкості одночасно, оскільки вони можуть конфліктувати в інтерфейсі. Оберіть цей для отримання повних метрик продуктивності.

### 6. `opencode-codebase-index`

* **Що робить:** Автоматично індексує файли вашого проєкту. Відстежує зміни та оновлює семантичний індекс у фоновому режимі.
* **Кому потрібно:** Розробникам програмного забезпечення.
* **Навіщо встановлювати:** Дозволяє виконувати швидкий і точний семантичний пошук по всій кодовій базі без ручного переіндексування.
